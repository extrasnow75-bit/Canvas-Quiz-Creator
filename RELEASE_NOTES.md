## What's new in v0.1.0

The first test release of Canvas Quiz Creator.

- **Quiz questions from a Google Doc.** Choose a Doc written in the eCampus quiz template, or paste its link. A Doc can hold several quizzes, one under each heading.
- **Classic Quizzes and New Quizzes.** Every question type in the template, including file upload. Each quiz can be built as either kind.
- **Several courses at once.** Tick every course that should get the quizzes. Each quiz is created unpublished, so you can check it in Canvas first.
- **Fixes poor formatting.** The app's own rules (no AI) write a corrected copy to a new "Reformatted questions" tab, with every change highlighted and answer and point changes listed for a person to check. The original questions are never changed.
- **Gemini as a last resort.** With a Gemini key, Gemini can lay out what the rules could not, and make changes you describe in plain English. Its work goes to a separate "Revised by Gemini" tab, and it never decides which answer is correct.
